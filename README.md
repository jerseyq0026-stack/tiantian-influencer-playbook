### 场景 1：从零起步，校准方向

**用户输入**：我想做减脂餐赛道，1000 粉，两个月内变现。主打低门槛、上班族也能做。
**提供的信息**：抖音 + 小红书双平台，5 条内容，评论有人问"求教程"，每天能投 2 小时。

**Skill 诊断输出**：

```
【判断轴：变现验证】
  起号 ≠ 涨粉。起号 = 从零拿到第一笔收入。
  1000 粉接商单基本轮不到你（品牌找合作至少几万粉起步）。

【初步假设（待验证）】
  假设一：你可能默认"商单是素人自媒体唯一变现路径"——但这条在你阶段走不通。
         你手里值钱的不是粉丝数，是"低门槛上班族减脂餐"这个切法。
         这东西如果能提炼成可教的方法论，卖课反而比等商单靠谱。
  假设二：你现在的 1000 粉可能不够"纯"——真正关心"怎么做减脂餐"的有多少？

【追问清单（按优先级）】
  1. 评论里说"求教程"的那些人——你点开过他们主页吗？真的是加班职业女性吗？
  2. 你自己在抖音搜"上班族减脂餐"，前 20 条里有几条做得比你好？
  3. 剪映不熟练 + 一周一条，产能瓶颈到底在哪一步？

【建议动作】
  1. 本周别发内容。把评论区"求教程"的评论抄出来，按"他们问的到底是什么"分类
  2. 写三道最常做的减脂菜的做法（拍照 + 文字），存好。有人真要，私信发给他，免费
  3. 让朋友圈一个不会做饭的朋友学这三道——他能照着做出来，你就能卖课；不能，先别卖
```

### 场景 2：已有 10 万粉，诊断变现路径

**用户输入**：10 万粉咖啡号，接不到广告，不知道卖什么。做了 8 个月，内容是"家庭手冲 + 咖啡豆测评"。
**提供的信息**：80% 粉丝是 25-35 岁女性，一二线城市，高消费能力。过往涨粉靠一条"3 分钟手冲教程"爆了 200 万播放。

**Skill 诊断输出**：

```
【定位一致性】
  ✅ 内容是"家庭手冲 + 咖啡豆测评"，粉丝是"爱喝咖啡的城市女性"——定位一致。
  ❌ 但定位本身不"搜不到"——咖啡号多如牛毛，竞品密集。

【变现承接】
  ⚠️ 10 万粉接不到广告 = 品牌不认为你有带货能力（咖啡商单本来就少）。
     商单是一次性成交，停接就归零。主动权不在你。

【建议：卖课，但先过资格关】
  你这套"家庭手冲"内容是怎么做起来的？
  你能不能把它提炼成一套方法，
  教给一个从零开始的人，让他也能做出咖啡号？

  → 能讲清楚：你就有卖课资格
  → 讲不清楚：先别卖，先把自己的方法理清楚

【变现结构建议（均为个案，具体情况具体分析）】
  低价钩子 + 高价课程包 + 小圈子：
    - 钩子：一份"手冲入门 10 问 10 答"，低价引流
    - 课程包：讲清楚"我是怎么火的、怎么复刻到另一个人身上"
    - 小圈子：每周拆 1-2 个学员账号

【硬前提（来源：54 条切片反复出现）】
  你必须自己先做出结果，才能教别人。
  市面上那种自己没一个万粉账号就敢出来教自媒体的，全是割韭菜。
```

### 场景 3：账号诊断（已有账号，给数据看问题）

**用户输入**：抖音号 1.2 万粉，做"职场穿搭 + 平价好物"，涨粉 6 个月，但粉丝增长停滞了 2 个月。
**提供的数据**：

- 内容：每周 3 条，视频时长 30-60 秒，爆款是"50 元通勤衬衫合集"（120 万播放）
- 粉丝画像：70% 是 22-28 岁女生，学生 + 刚入职，三四线城市
- 互动：平均点赞 300-500，评论 5-15 条，收藏比点赞高 2:1
- 变现：开过一次橱窗，卖了 12 件衬衫，客单价 59 元，利润率 30%
- 没接商单，没导私域

**Skill 诊断输出**：

```
【B2 诊断五步（固定顺序，不跳）】

  Step 1 — 定位一致性
  ❌ 你的"职场穿搭"和粉丝画像不匹配。
     粉丝是三四线、学生 + 刚入职，但"职场穿搭"默认是一二线都市白领。
     爆款"50 元通勤衬衫合集"本质上是"平价穿搭"，不是"职场穿搭"。
     你自己可能没意识到：粉丝要的是"便宜好看"，你讲的是"职场品味"。

  Step 2 — 流量结构
  ⚠️ 拉新堆 ≠ 转化堆。收藏比点赞 2:1 说明"有人想拿东西"，
     但没人真正"被种草想买"。
     你那 120 万爆款，转橱窗只卖了 12 件——流量没导到转化上。

  Step 3 — 人群纯度
  ⚠️ 1.2 万里真正对你的"平价好物"感兴趣的有多少？
     学生、刚入职、三四线——这个群体追求的是"性价比"，
     但你内容的核心卖点可能是"职场穿搭"，两者错位了。

  Step 4 — 变现承接
  ❌ 你开过橱窗卖衬衫，客单价 59 元，利润率 30%（17.7 元）。
     但你没做：
     - 复购（衬衫是消费品，不是一次性）
     - 私域（粉丝没导过来，下次去哪找你？）
     - 后端（衬衫是引流品，后端有没有更高客单价的东西？）

  Step 5 — 扩展可行性
  ⚠️ 如果继续做"职场穿搭"，涨粉可能继续停滞——
     定位和人群不匹配，内容再精致也没用。
     但如果转向"三四线女生平价穿搭"（你的爆款已经验证过），
     可能打开新的增长窗口。

【综合建议】
  1. 先改定位：从"职场穿搭"改成"三四线女生平价通勤穿"——
     你的爆款已经验证了这个方向有人看，只是你自己没认
  2. 立刻导私域：评论区引导"想看更多的进群/私信"，别在公开场合直接说
  3. 卖衬衫的同时做复购："衬衫 + 通勤鞋 + 通勤包"的组合，后端接更高客单价

【数据缺口（需要你自己补）】
  - 你没说粉丝的评论里最常问什么——是问"链接"还是"搭配技巧"？
  - 你那件爆款衬衫的货源渠道和毛利——要算清楚才能定价
```

## 安装

### 方式一：一行命令（推荐）

```bash
npx skills add <your-github-username>/tiantian-influencer-playbook
```

## 蒸馏了什么

### 1 条判断轴（贯穿所有层级）

| 轴        | 一句话                                       |
| -------- | ----------------------------------------- |
| **变现验证** | 任何内容、定位、流量的价值，最终都要过"能不能变现"这一关。变不了现 = 不该做。 |

### 4 层递进框架

| 层级             | 解决什么                  | 核心判据                        |
| -------------- | --------------------- | --------------------------- |
| **L1 我适不适合**   | 有没有可交付的东西、有没有天赋、失败耐受  | 判断轴（能不能变现）、天赋四问、失败不是终点      |
| **L2 做什么位置**   | 人群是谁、供给是不是搜不到、搜不到才有溢价 | 搜不到才做、人群四问、复购品选品判据          |
| **L3 怎么把它做出来** | 内容边界、标题、频率、AI 工作流     | 内容边界=人群边界、AI 先检索自己的爆款、黑帖不删  |
| **L4 怎么放大**    | 产品化、投流、私域、团队分钱        | 一次生产多次销售、先赚再投、公域导私域、利润跟绩效挂钩 |

### 5 个心智模型

| 模型         | 一句话                         | 来源         |
| ---------- | --------------------------- | ---------- |
| **变现验证**   | 涨粉、播放都是指标游戏，起号=从零拿到第一笔收入    | 反复使用 20+ 次 |
| **搜不到才做**  | 能搜到大量同款=只能比价，搜不到才有溢价        | 类目判断的基础    |
| **先做出来再教** | "自己都没有一个万粉账号就敢出来教自媒体"=割韭菜   | 卖课资格判据     |
| **公域导私域**  | 平台粉丝不是你的，能主动触达的才是           | 私域水源三问     |
| **三层收入结构** | 现金流（低价钩子）→ 标准化产品（课/圈）→ 高价咨询 | L4-2 产品化   |

### 咨询协议（怎么问、怎么答）

这不是套人设。Skill 保留了天总真实的咨询节奏：

- 先校准目标，不接受用户给的模糊目标
- 一次给初步假设 + 追问清单（最多 12 题，必答 6 题）
- 定位建议必须可验证，给一个最小动作 + 一个反例
- **公开场合绝对不能提价格或引导交易**（整理者归纳，非她原话）

### 她没讲过的（禁止编造）

- 市场调研方法：赛道规模判断、数据渠道、竞品报告
- 任何指标拆解方法：涨粉率、收藏点赞比、主页占比等派生口径
- "你其实不是想做 X"这种替用户改定位的句式（样本里没有）

### 一手来源（全部在 references/ 目录）

| 文件                               | 内容                                               |

| `references/intake-questions.md` | 完整追问清单（首批 12 题 + 备用池）                            |

### 溯源边界（重要）

> 抖音不公开留存直播回放，主播主页无回放入口，切片页无"原视频"链接。
> 因此**只能索引到切片本身，不能到原直播**。
> 所有引用格式为「切片 ID + 切片内时间戳」。
> `#天总专属二创大赛` 标签的切片属官方授权二创，其余为搬运。
