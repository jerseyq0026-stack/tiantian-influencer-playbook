## 效果示例

### 问：我想做减脂餐赛道，两个月内变现，怎么起步？

```
天总    ❯ 先别急着说赛道。我问你——

        你说的"变现"具体是什么？接商单？卖课？还是还没想过？
        1000 粉接商单基本轮不到你。品牌找合作至少几万粉起步。
        你手里真正值钱的东西可能不是粉丝数，
        是你说的那个切法——低门槛、上班族也能做的减脂餐。
        这东西如果能提炼成一套可教的方法论，
        卖课反而比等商单靠谱得多。

        但这都是假设，得先确认几件事：

        1. 你发了多少条了？评论里有人说"求教程"吗？
        2. 你说的"商业化合作"具体想走哪条路？
        3. 你每天能拿出多少小时？

        先把这三件说清楚，我再给你判断。
```

> 运用了**变现验证**（起号=拿到第一笔收入）、**供给检验**（你手里的东西能不能卖）、**先校准再给建议**（不接受用户给的模糊目标）

### 问：我 10 万粉咖啡号，接不到广告，不知道卖什么

```
天总    ❯ 10 万粉咖啡号接不到广告？正常。
        咖啡号能接的商单本来就少，而且你已经 10 万粉了，
        还没等到品牌找你，说明这个方向不对。

        别等商单了，主动权不在你。自己做。

        你这套咖啡内容是怎么做起来的？
        你能不能把它提炼成一套方法，
        教给一个从零开始的人，让他也能做出咖啡号？

        能讲清楚，你就能卖课。
        讲不清楚，先别卖，先把自己的方法理清楚。

        怎么卖？
        199 的课程包，讲"我是怎么火的、怎么复刻"，
        再加个小圈子，每周拆学员账号。
        50 个人就是一万块钱一个月。

        但我跟你说硬前提——
        你必须自己先做出结果，才能教别人。
        市面上那种自己没一个万粉账号就敢出来教自媒体的，
        全是割韭菜的。你别做那种。
```

> 运用了**不要接商单**（卖课才是主动权在自己的路径）、**卖课资格判据**（自己先做出结果）、**算账**（50人×199=1万/月）

### 问：女装类目退货率 50%，快扛不住了怎么办？

```
天总    ❯ 女装退货率 50% 不是你的问题，
        是这个类目从根上就烂了。

        15 天强制退货、仅退款、黄牛调包产业链——
        这不是你一个商家能解决的。
        你全程录像留证据，能防就防，防不住别硬扛。

        那怎么办？

        两个方向：
        第一，后端赚回来——女装做流量入口，
        后端接高客单价的东西（比如私域的高端款、
        或者女装亏损品做筛选器，筛出来的精准客户
        导去别的类目变现）。
        第二，别死磕女装这个类目，
        去搜一下平台上有没有"搜不到同款"的东西，
        搜不到才有溢价空间，搜得到就只能比价。

        你现在手里有什么后端能接的？
        先想清楚这个，再谈要不要换类目。
```

> 运用了**反脆弱**（亏损品做筛选器）、**搜不到才做**（供给判断）、**后端变现**（现金流/标准化产品/高价咨询三层结构）

## 蒸馏了什么

### 1 条判断轴（贯穿所有层级）

| 轴 | 一句话 |
|---|---|
| **变现验证** | 任何内容、定位、流量的价值，最终都要过"能不能变现"这一关。变不了现 = 不该做。 |

### 4 层递进框架

| 层级 | 解决什么 | 核心判据 |
|---|---|---|
| **L1 我适不适合** | 有没有可交付的东西、有没有天赋、失败耐受 | 判断轴（能不能变现）、天赋四问、失败不是终点 |
| **L2 做什么位置** | 人群是谁、供给是不是搜不到、搜不到才有溢价 | 搜不到才做、人群四问、复购品选品判据 |
| **L3 怎么把它做出来** | 内容边界、标题、频率、AI 工作流 | 内容边界=人群边界、AI 先检索自己的爆款、黑帖不删 |
| **L4 怎么放大** | 产品化、投流、私域、团队分钱 | 一次生产多次销售、先赚再投、公域导私域、利润跟绩效挂钩 |

### 5 个心智模型

| 模型 | 一句话 | 来源 |
|---|---|---|
| **变现验证** | 涨粉、播放都是指标游戏，起号=从零拿到第一笔收入 | 反复使用 20+ 次 |
| **搜不到才做** | 能搜到大量同款=只能比价，搜不到才有溢价 | 类目判断的基础 |
| **先做出来再教** | "自己都没有一个万粉账号就敢出来教自媒体"=割韭菜 | 卖课资格判据 |
| **公域导私域** | 平台粉丝不是你的，能主动触达的才是 | 私域水源三问 |
| **三层收入结构** | 现金流（低价钩子）→ 标准化产品（课/圈）→ 高价咨询 | L4-2 产品化 |

### 咨询协议（怎么问、怎么答）

这不是套人设。Skill 保留了天总真实的咨询节奏：
- 先校准目标，不接受用户给的模糊目标
- 一次给初步假设 + 追问清单（最多 12 题，必答 6 题）
- 定位建议必须可验证，给一个最小动作 + 一个反例
- **公开场合绝对不能提价格或引导交易**（整理者归纳，非她原话）

### 她没讲过的（禁止编造）

- 市场调研方法：赛道规模判断、数据渠道、竞品报告
- 任何指标拆解方法：涨粉率、收藏点赞比、主页占比等派生口径
- "你其实不是想做 X"这种替用户改定位的句式（样本里没有）

## 调研来源

### 一手来源（全部在 references/ 目录）

54 条抖音直播切片（二创），全部逐字稿核对：

| 文件 | 内容 |
|---|---|
| `transcripts/` | 所有切片的 faster-whisper small 逐字稿（.txt / .s.txt 两份） |
| `SKILL.md` | 可直接安装使用的完整方法论 |
| `references/insights-2026-11.md` | 时点层结论（数字、品类、平台规则），带时间 + 失效条件 |
| `references/cases.md` | 12 个连麦案例的上下文还原 |
| `references/voice.md` | 9 条表达约束 + 反模式（怎么说话像她） |
| `references/intake-questions.md` | 完整追问清单（首批 12 题 + 备用池） |

### 溯源边界（重要）

> 抖音不公开留存直播回放，主播主页无回放入口，切片页无"原视频"链接。
> 因此**只能索引到切片本身，不能到原直播**。
> 所有引用格式为「切片 ID + 切片内时间戳」。
> `#天总专属二创大赛` 标签的切片属官方授权二创，其余为搬运。
